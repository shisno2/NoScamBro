# 🎮 Geometry Dash Real-Time Vision AI Bot (ИИ для прохождения уровней GD)

Интеллектуальный ИИ-автопилот для игры **Geometry Dash**, который в **реальном времени** захватывает изображение с экрана, анализирует препятствия (шипы, блоки, сферы/орбы, пропасти) с помощью компьютерного зрения (OpenCV) и совершает прыжки с аппаратной точностью (sub-millisecond `SendInput`).

---

## ⚡ Особенности и возможности

1. **Реальное зрение (Real-Time Computer Vision)**:
   - Анализ до 120–200+ FPS без задержек.
   - Автоматическое определение положения куба и уровня пола.
   - Сканирующий коридор (Lookahead Scan Ray), детектирующий препятствия перед кубом.
   - Распознавание шипов (треугольные контуры и контрастные грани).
   - Распознавание орбов / сфер (желтые, розовые, синие, красные) по цветовой гамме HSV.
   - Поддержка режимов: **Куб (Cube)**, **Корабль / Волна (Ship/Wave)**, **НЛО (UFO)**.

2. **Сверхбыстрый отклик (Zero-Latency SendInput)**:
   - Использует прямой низкоуровневый Win32 API `SendInput` (время срабатывания < 0.1 мс), исключая задержки стандартных библиотек автокликеров.
   - Поддерживает эмуляцию:
     - Левого клика мыши (`Left Mouse Click`)
     - Пробела (`Spacebar`)
     - Стрелки вверх (`Up Arrow`)

3. **Киберпанк интерфейс (PySide6 / Qt GUI)**:
   - Живой монитор с визуализацией: подсвечивает куб (зеленый), шипы (красный), орбы (желтый), линию прыжка (оранжевая линия триггера) и сканирующий коридор.
   - Отображение текущего FPS и задержки (Latency в миллисекундах).
   - Интуитивные ползунки для калибровки расстояния прыжка, уровня пола и скорости уровня (0.5x, 1.0x, 2.0x, 3.0x, 4.0x).

4. **Встроенный Симулятор (Offline Demo Mode)**:
   - Позволяет мгновенно протестировать и увидеть работу ИИ прямо в окне программы даже без запущенного Geometry Dash!

5. **Глобальные горячие клавиши**:
   - `F6`: **СТАРТ / ПАУЗА** ИИ прямо во время игры.
   - `F7`: **СТОП** (мгновенная остановка и сброс зажатых кнопок).

## 🚀 Быстрый запуск

### Вариант 1 (Самый простой — 1 клик):
Дважды кликните по файлу **`run_ai.bat`** (или `run_gd_ai.bat` в корне проекта).

### Вариант 2 (Через терминал):
```bash
python main.py
```

### Вариант 3 (Режим максимальной производительности Headless CLI):
```bash
python main.py --cli --input mouse --speed 1.0
```

## 🛠 Руководство по настройке и калибровке

1. Запустите Geometry Dash в окне или режиме "В окне без рамки" (Borderless Windowed).
2. Запустите ИИ (`run_ai.bat`). Он автоматически найдет окно `"Geometry Dash"`.
3. Зайдите в любой уровень (или Practice Mode) и нажмите **F6** — ИИ начнет проходить уровень.
4. Если куб прыгает слишком рано или поздно:
   - **Jump Trigger Distance**: увеличьте, если прыгает слишком поздно; уменьшите, если прыгает слишком рано.
   - **Level Speed**: установите скорость, соответствующую порталу скорости на уровне (1x, 2x, 3x).

## 📁 Структура проекта
- `main.py` — Главная точка входа (GUI или CLI).
- `gui.py` — Современный графический интерфейс на PySide6 с живым HUD.
- `detector.py` — Движок компьютерного зрения (обнаружение шипов, платформ, орбов, коридора).
- `bot_brain.py` — Принятие решений, расчет времени прыжка и физика режимов.
- `capture.py` — Быстрый захват окна Geometry Dash (MSS + Win32 GDI).
- `inputs.py` — Микросекундный аппаратный ввод `SendInput`.
- `simulator.py` — Встроенный движок симуляции Geometry Dash для тестов.
- `run_ai.bat` — Батник быстрого запуска.
