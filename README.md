# GameDev Tycoon: Studio Master Pro (C++ Native .exe) 🚀🎮

Нативный симулятор студии разработки видеоигр, написанный на **C++ (Win32 API + GDI+ + WinMM)**, компилируемый напрямую в самостоятельный исполняемый файл **`.exe`** без использования сторонних фреймворков и .NET/C#.

---

## ⚡ Как запустить готовую игру:

1. **Простой запуск**:
   - Дважды кликните по файлу **[`GameDevTycoonPro.exe`](file:///C:/Users/shisn/.gemini/antigravity/scratch/BuildAGameDEV/GameDevTycoonPro.exe)**!
   - Никаких браузеров, никаких интерпретаторов — мгновенный нативный запуск на чистом C++!

2. **Сборка из исходников (если захотите внести правки)**:
   - Запустите скрипт **[`build_and_run.bat`](file:///C:/Users/shisn/.gemini/antigravity/scratch/BuildAGameDEV/build_and_run.bat)**.
   - Или одной командой компилятора:
     ```bash
     g++ -O3 main.cpp -o GameDevTycoonPro.exe -mwindows -lgdiplus -lgdi32 -lwinmm
     ```

## 🕹️ Геймплей и управление:

- **Мышь**:
  - Нажатия на вкладки левого меню (Офис, Новая игра, Портфолио, Команда, Движки, Исследования, Улучшения, Ачивки).
  - Управление разработкой, кнопка **"Охота на баги"** (клик по жукам в мини-игре перед релизом!).
  - Запуск фриланс-заказов (+$3,000).

- **Быстрые горячие клавиши**:
  - **`[P]`**: Пауза / Возобновление времени.
  - **`[1]`, `[2]`, `[3]`**: Скорость времени (1x, 2x, 5x).
  - **`[N]`**: Открыть конструктор новой игры.
  - **`[F]`**: Быстрый фриланс (+$3,000 в бюджет).
  - **`[B]`**: Охота на баги в мини-игре.
  - **`[C]`**: Кранч-режим (удвоенная скорость разработки!).
  - **`[R]`**: Выпустить готовую игру в релиз и получить оценки критиков.
  - **`[ENTER]`**: Подтвердить старт игры или закрыть окно оценок прессы.
  - **`[T]`**: Обучить ведущего сотрудника в команде.
  - **`[E]`**: Собрать некстген движок Titan RayTracing.
  - **`[1-6]`**: Выбор жанров в конструкторе.
  - **`[Q, W, E, R, T, Y]`**: Выбор сеттингов в конструкторе.
  - **`[Z, X, C, V]`**: Выбор платформы в конструкторе.
