# GameDev Tycoon: Studio Master 🎮

Полноценный симулятор студии разработки видеоигр с интерактивным интерфейсом, управлением командой, исследованиями технологий, офисами, рецензиями игровой прессы и продажами на игровом рынке.

## ✨ Ключевые особенности игры

1. **Создание и проектирование собственных игр**:
   - Выбор названия (или генератор крутых названий).
   - Подбор жанра (RPG, Экшен/Шутер, Стратегия, Симулятор, Хоррор, Головоломка).
   - Выбор сеттинга / тематики (Фэнтези, Киберпанк, Космос, Постапокалипсис, Зомби и др.).
   - Целевые платформы (ПК/Steam, консоли PlayBox, Switchy, Мобилки, VR).
   - Выбор движка (от базового 2D до фотореалистичного Titan 5 Engine).
   - Тонкая настройка баланса усилий команды: ползунки Геймплея/Кода, Графики/Арта и Музыки/Звука под каждый конкретный жанр.
   - Предрелизные маркетинговые кампании (блогеры, трейлеры, соцсети).

2. **Офис и визуализация команды**:
   - Живая комната со столами и персонажами.
   - Во время разработки над экранами вылетают частицы очков (`+Код`, `+Арт`, `+Звук`, `+Баги`, `+RP`).
   - Расширение недвижимости: от родительского гаража до высотного небоскрёба!

3. **Интерактивная мини-игра "Охота на баги"**:
   - Возможность кликать и уничтожать баги прямо перед релизом, чтобы спасти оценку критиков!

4. **Рецензии прессы и оценки**:
   - 4 независимых игровых журнала выставляют баллы (от 1.0 до 10.0) и пишут рецензии.
   - Праздничное конфетти и фанфары при создании шедевра.

5. **Экономика и продажи**:
   - Динамический рынок: график продаж, еженедельная прибыль, фанаты студии.
   - Срочные фриланс-контракты для покрытия зарплат и аренды.

6. **Персонал и лаборатория исследований**:
   - Агентство найма талантов (программисты, 3D-художники, композиторы).
   - Прокачка и курсы повышения квалификации для сотрудников.
   - Древо технологий (RP очки) для разблокировки новых жанров, движков и платформ.

## 🚀 Запуск игры

Просто откройте файл `index.html` в любом современном браузере:
- Дважды кликните по `index.html` или откройте через Chrome / Edge / Firefox.
