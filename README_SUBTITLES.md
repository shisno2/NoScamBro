# 🎯 AI WordSync Subtitles (Субтитры слово в слово)

Программа с графическим интерфейсом (GUI) для мгновенного создания высокоточных субтитров **слово в слово** из любого видео или аудиофайла.

## ✨ Возможности
- **Drag & Drop**: Просто перетащите любое видео (MP4, MKV, AVI, MOV, WEBM) или музыку (MP3, WAV, FLAC, OGG, M4A) в окно программы.
- **Точность "Слово в слово"**: Каждое отдельное слово получает свой точный тайминг благодаря AI-движку `faster-whisper` и алгоритмам VAD.
- **Стили субтитров**:
  - **Слово в слово (Reels / Shorts / TikTok)**: по 1 или по несколько слов на строку.
  - **Караоке ASS**: красивый эффект подсветки слов прямо во время их произношения (поддерживается плеерами VLC, MPV и видеоредакторами Premiere, CapCut, DaVinci).
  - **Классический SRT**: стандартные субтитры фразами.
  - **Все форматы разом**: сохраняет `.srt`, `_words.srt`, `_karaoke.ass`, `.vtt` и чистый текст `.txt`.
- **Вшивание в видео (Hardsub)**: Одной галочкой субтитры намертво вшиваются в видеофайл через FFmpeg.
- **Поддержка GPU**: Автоматически использует видеокарту NVIDIA (CUDA) для молниеносной обработки, либо процессор (CPU).

## 🚀 Быстрый запуск
Просто дважды кликните по файлу:
```
Запустить_Генератор_Субтитров.bat
```
или из папки `subtitles_app`:
```
subtitles_app\run.bat
```

## 🛠 Ручной запуск через терминал:
```bash
python subtitles_app/main.py
```
